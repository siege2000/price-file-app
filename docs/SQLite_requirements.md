# Main Focus
The user needs to be able to view the data in the SQLite database to enable direct editing. The data structure is the same as Access, so I propose a UI that opens then a button is pressed in the qt_app page. 

## Layout
Should be able to select to view any of the tables
User will need to be able to select a supplier and then view all Details for that supplier (Stock Items), and then edit or delette rows in that window
The user should also be able to paste in a list of codes to bring up items for deletion (effectively a select * from details where barcode in ('3535','43535') as an example)
