This folder contains 2 Microsoft Access files in a sub folder called tests. They are databases that hold price file data for use within RxOne. 
suppliers.mdb is the test database for the new app
suppliers rename.mdb has the legacy apps data

Each test the goal will be to compare data for a supplier to make sure the data is valid.

Results will be in an HTML document, this document will grow with the results of various tests and be easy to read, but professional.
